# Alazhar City Delivery

موقع طلبات (بقالة / مشروبات / ألبان) بيبعت الطلب على واتساب. HTML + CSS + JS عادي، بدون أي build، ومناسب لـ GitHub Pages.

## الملفات

| الملف | وظيفته |
|---|---|
| `config.js` | **الملف الوحيد اللي بتعدله**: المنتجات، الأسعار، رقم واتساب، مصاريف التوصيل |
| `index.html` | الصفحة (التصميم والمنطق) |
| `images/` | صور المنتجات واللوجو (`.webp`) |
| `icons/` | أيقونات الموقع والموبايل |
| `manifest.json` | بيخلي الموقع يتثبت على الموبايل كأنه تطبيق |

## إضافة منتج جديد

1. حط الصورة في `images/` باسم إنجليزي بدون مسافات (مثال `pepsi.webp`) — يفضل أقل من 60KB.
2. في `config.js` انسخ سطر منتج وعدّل عليه:

```js
{ id: 'pepsi', name: 'بيبسي - 330 مل', price: 15, cat: 'drinks', img: 'images/pepsi.webp' },
```

- `price: null` = السعر مش محدد، وهيظهر للعميل «السعر عند التأكيد» ومش بيدخل في الإجمالي.
- `soldOut: true` = المنتج خلص (بيظهر «غير متاح»).

## تجربة الموقع على جهازك

افتح `index.html` بالدبل كليك، أو شغّل `python -m http.server` وافتح `http://localhost:8000`.
